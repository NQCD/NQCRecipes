# NQCRecipes

This repository provides the documentation and resources for example complex workflows and tutorials using [NQCDynamics](https://github.com/NQCD/NQCDynamics.jl/) and associated packages.
The tutorials and workflows are available [here](https://nqcd.github.io/NQCRecipes/).

More information on the NQCDynamics package such as: how to install, getting started, implemented dynamic methods and basic examples are avaialble in the [documentation](https://nqcd.github.io/NQCDynamics.jl/stable/).
